# PT-047：社科类通俗作品创作智能体平台

> Social Science Agent Cluster Platform | SPDT-005 媒体内容制造 · 第 7 PDT
> 版本：V1.1（纳入审核1.md 意见）

## 一句话定位

将社科通俗作品全自动生产体系方法论工程化为多智能体协作平台——主编居中协调，选材/编排/评审/生成各司其职，反思智能体处理修订循环，实现从知识库到多模态内容成品的端到端自动化。

## 核心理念

**强约束 + 受控多样性。** LLM 不做作文题，只做选择题和填空题：
- 模型只做「选择题」（选模板、填槽位），不做「作文题」（自由创作）
- 叙事结构、史观立场、文风基调均由规则引擎预先锁定
- 表现力参数化而非概率随机输出

## 智能体集群（V1.1 新增：反思+合规扫描）

```
主编智能体 (ChiefEditor) ── 全局协调，控制平面
    │
    ├── 冷启动智能体 (ColdStart)       ── 专家经验 → 可执行配置
    ├── 选材智能体 (MaterialScout)     ── 知识节点评分筛选 + 挖掘模式
    ├── 编排智能体 (Orchestration)      ── 模板选择 + COG 章节脚本 + 降级策略
    ├── 评审智能体 (AdversarialReview) ── 5 对抗 Agent 轮攻 + 置信度加权
    ├── 反思智能体 (Reflection)        ── 评审报告 → 修改指令（V1.1 新增）
    ├── 生成智能体 (Generation)          ── LLM 填槽 + 上下文感知 + 流式打断
    └── 输出智能体 (OutputRenderer)     ── 多模态渲染

支撑型智能体
    ├── 文风包管理 (StyleManager)        ── 含版本Diff可视化（V1.1）
    ├── 史观包管理 (HistorioManager)
    ├── 知识库管理 (KnowledgeBaseAgent)
    └── 合规扫描 (ComplianceScan)        ── 配置漂移检测（V1.1 新增）
```

## 流水线

```
冷启动 ── 选材 ── 编排 ── 评审(轻) ── 生成 ── 评审(重) ── [反思] ── 输出
                                                  ↑若不通过↓
                                            （修订后重新提交）
```

| 阶段 | 核心产出 | 是否 LLM 调用 |
|------|---------|------------|
| 冷启动 | Series Profile 快照 | 辅助（生成配置草稿） |
| 选材 | 知识点序列（JSON） | 否 |
| 编排 | COG 章节分镜脚本（JSON） | 否 |
| 评审（轻） | 通过/修订 | 规则引擎 |
| 生成 | 渲染文本 | 是（核心） |
| 评审（重） | 终审通过/人工干预 | LLM 攻击 |
| 输出 | MD / SSML / 动画分镜 / 知识卡片 | 否 |

## 生产资料库

| 资料库 | 路径 | 说明 |
|--------|------|------|
| 知识库 | `kb/` | 事件/人物/制度/观念四元组，含选材加权字段 |
| 叙事模板库 | `templates/` | TPL-01~TPL-10 完整规格 |
| 文风包库 | `style_packs/` | 五层定义（黄仁宇式/费曼式/通俗演义式） |
| 史观包库 | `historio_packs/` | 五维立场向量 + 情绪基调 + 价值观词表 |
| 读者画像库 | `reader_personas/` | 认知基线/情感原型/语言亲和度 |

## 关键设计原则

1. **主编居中路由**：编排不直接呼叫生成，所有流转经主编决策
2. **上下文快照传递**：主编维护作品级快照 ID，智能体间不维护重复状态
3. **全部链路可审计**：每个决策节点写入结构化日志（who/when/what/why）
4. **文风包与史观包正交**：怎么说（文风）≠ 说什么、站在哪边（史观）
5. **四层注入**：史观 → 读者连接 → 文风 → 冲击力，逐层约束 LLM 输出
6. **幂等性**：选材/编排完全幂等，生成阶段 Slot 输出缓存
7. **降级兜底**：模板选择无法唯一确定时，采用安全模板（TPL-01/TPL-09）并标记 Warning
8. **置信度加权**：评审置信度 <0.6 的 Warning 仅作参考，不阻断流程
