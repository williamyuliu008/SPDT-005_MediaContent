# PT-048 · AI写书修炼场

> 为自己写一本AI辅助学习手册 —— AI时代素养训练项目

## 项目概述

**核心任务**：在自己感兴趣但不熟悉的领域，用AI辅助从零构建一本3-5万字的学习用书。

这不是"用AI写书"，而是"用写书来学习"——书籍是副产品，学习者七个品味维度的系统性提升才是核心产出。

## 与PT-047的关系

| | PT-047 社科内容生产 | PT-048 AI写书修炼场 |
|:---|:---|:---|
| 核心输出 | 书稿（面向读者） | 人+书的共同成长（面向学习者） |
| AI角色 | 内容生产者（替人写） | 认知脚手架（帮人学） |
| 验收标准 | 产出物质量 | 产出物质量 + 认知变化幅度 |

## 四阶段流水线

| 阶段 | 时长 | 核心交付物 | 训练品味 |
|:---|:---|:---|:---|
| 第一阶段：立项定义 | ~1周 | 书籍立项书.md | 目标 + 元认知 |
| 第二阶段：架构设计 | ~1周 | 全书架构蓝图.md | 过程 + 作品 |
| 第三阶段：写作执行 | 3-6周 | 各章草稿.md + 流程日志 | LLM + 作品 |
| 第四阶段：整合复盘 | ~1周 | 完整书籍.md + 四品味自评报告.md | 元认知 + 伦理 |

## 七品味覆盖

1. **目标的品味** — 定义"我到底想学什么"
2. **过程的品味** — 设计AI辅助写作流程
3. **作品的品味** — 评估逻辑链条和认知坡度
4. **LLM的品味** — 知道什么时候用AI、什么时候自己来
5. **协作品味** — 多智能体/人协作（可选延展）
6. **伦理品味** — AI使用透明度和引用管理
7. **元认知品味** — 追踪认知变化，复盘"我真正学会了什么"

## 快速开始

1. **克隆/下载**本项目
2. **阅读** `docs/平台设计需求.md` 理解完整框架
3. **从第一阶段开始**：填写 `templates/phase1/书籍立项书模板.md`
4. **每阶段完成后**与BookMentor智能体（或AI助手）交流，获取反馈
5. **四阶段完成后**，产出完整书籍 + 四品味自评报告
