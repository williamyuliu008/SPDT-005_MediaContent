## 一、需求总览

### 1.1 项目背景

SmartTextPlatform 六赛道文字创作能力已通过 V3 递进式管道升级和 MKT 内阁质量验收。现需将基础能力嵌入日常 AI 产业情报运营，通过五个自动化频道 + 一个网站 + 一个知识底座，实现"每日生成→网站分发→知识沉淀"的完整闭环。

### 1.2 总体架构

```
Survey(数据采集) + 已有例行任务(CI Engine/智囊团/ModLib)
           │
           ▼
SmartTextPlatform(六赛道文字生成: A/B/C/D/E/F)
           │
           ▼
🌐 AI 瞭望台网站(每日自动更新 · 全文检索 · 频道浏览)
           │
           ▼
🧠 AI 知识底座(三层: 频道归档 → 实体图谱 → 决策框架)
```

## 二、频道需求规格

### SR-CH-001：AI 竞争态势日报

#### 概述

每日自动生成一份 AI 产业竞争态势日报，聚焦 10 家核心 AI 公司的动态变化。这是五个频道中最先上线的旗舰频道。

#### 输入

| 数据源 | 来源 | 格式 | 更新频率 |
|--------|------|------|----------|
| CI Engine 每日简报 | `ci-engine/reports/briefs/*.json` (10 家公司事件) | JSON | 每早 09:30 |
| AI 智囊团每日扫描 | `D:\7_MKT\_05_ops\daily_signals\` | Markdown | 每早 09:00 |
| Survey 竞品深潜 | `D:\9_infra\survey` competitor.py 按需调用 | Markdown | 按需 |

#### 输出

```
文件路径: D:\92_products\SmartTextPlatform\channels\compete\YYYY-MM-DD.md
格式: Markdown
字数: 1500-3000 字
```

**内容模板：**

```markdown
# AI 竞争态势日报 — YYYY-MM-DD

## 今日重大信号（B 深产赛道）
[10 家公司过去 24h 动作 Top 5，每条 100-150 字结构化描述]

## 格局变化判断（F 观点赛道）
[信号对竞争格局的潜在影响，正反方分析，含判断]

## 模型层动态（B 深产赛道）
[GPT/Gemini/Claude/文心/通义 等最新进展]
| 公司 | 模型 | 变化 | 影响评估 |

## 应用层突围（F 观点赛道）
[AI 原生应用的新模式/新产品，论证为什么值得关注]

## 明日关注（B 深产赛道）
[预测接下来 24-48h 最值得关注的 3-5 个动向]
```

#### SmartTextPlatform 调用

| 模块 | 赛道 | 输入 | 说明 |
|------|------|------|------|
| 今日重大信号 | B 深产 | 10 家公司事件 JSON | 碎片信号→结构化 TOP 5 |
| 格局变化判断 | F 观点 | 上一步输出 + 历史背景 | 信号→格局判断 |
| 模型层动态 | B 深产 | 模型相关事件子集 | 专表化呈现 |
| 应用层突围 | F 观点 | 应用相关事件子集 | 论证为什么值得关注 |
| 明日关注 | B 深产 | 全量信号 + 趋势 | 预测性建议 |

#### 质量要求

| 指标 | 目标值 |
|------|--------|
| 10 家公司覆盖 | 100%（每家至少 1 条信号/周） |
| 判断有论据支撑 | 每条判断 ≥ 1 条具体论据 |
| 延迟 | 数据采集完成后 ≤ 60s 生成 |
| Stage 差异度 | B/F 赛道相邻相似度 < 0.50 |


```markdown
[1 个 AI 产品的完整设计解构：信息架构/交互流程/视觉语言]

## 🆕 跨平台灵感·鸿蒙启示
```

## 三、App Store 扫描能力需求规格

### SR-APP-001：App Store 扫描能力

#### 概述

新增公共能力模块，定期扫描 Android（Google Play）和 iOS（App Store）中 AI 品类 APP 的排名变化、新上榜、描述文本、用户评价，为"AI 设计前线"频道提供素材。

#### 扫描目标

| 平台 | 目标 | 扫描内容 |
|------|------|----------|
| Google Play | AI 品类 Top 100 | 排名变化、新上榜、描述、评分、更新日志 |
| Apple App Store | AI/效率/教育 品类 Top 100 | 同上 |
| 华为应用市场 | AI 品类 Top 50（对比基准） | 同上 |

#### 技术约束

- **不依赖官方 API**（Google Play API 有配额限制，App Store API 需开发者账号）
- **优先级方案：** Survey web_search（搜索"best AI apps 2026"） + 公开榜单网站抓取（如 App Annie/SensorTower 公开报告、Product Hunt AI 分类）
- **频次：** 每周扫描 1 次（与周报频道同步）
- **输出格式：** 结构化 JSON

```json
{
  "scan_date": "2026-06-17",
  "platforms": {
    "android": {
      "top_new": [
        {"name": "App名", "category": "AI", "rank": 5, "rating": 4.5, "description_summary": "...", "design_highlights": ["..."]}
      ],
      "ranking_changes": [
        {"name": "App名", "rank_change": "+12", "reason_inferred": "..."}
      ]
    },
    "ios": { /* 同上结构 */ },
    "harmonyos": { /* 同上结构，作为对比基准 */ }
  },
  "cross_platform_insights": [
    "跨平台设计趋势1",
    "可迁移至鸿蒙的设计模式2"
  ]
}
```

#### 设计灵感提取 Pipeline

```
原始 App 数据(排名+描述+评分)
        │
        ▼
Survey analyzer: 提取设计特征关键词
  — 交互模式: 语音/手势/卡片/沉浸式/多模态
  — 视觉语言: 极简/毛玻璃/新拟态/深色模式/渐变
  — 信息架构: Tab式/瀑布流/仪表盘/对话式
  — 动效: 微交互/场景过渡/加载动画
        │
        ▼
SmartTextPlatform C 创意赛道: 设计特征→"灵感卡片"
  例: "Google Play 上新上榜 #3 的 AI 笔记应用采用'对话式信息架构'——
       用户与 AI 的聊天即笔记，颠覆了传统文件夹层级。
       → 鸿蒙启示: 鸿蒙的'服务卡片'可以借鉴对话式组织方式，
          将 AI 能力以'对话卡片流'而非'功能菜单'呈现给用户"
```

#### 质量要求

| 指标 | 目标 |
|------|------|
| 每周扫描完成率 | 100% |
| 每平台 Top 10 覆盖 | 100% |
| 设计特征提取准确率 | ≥ 80%（人工抽检） |
| 跨平台灵感产出 | ≥ 3 条/期 |

#### 三层结构

**第一层：内容归档（自动化）**

```
knowledge_base/
├── channels/                      ← 频道产出自动镜像
│   ├── compete/
│   │   ├── 2026-06/
│   │   │   ├── 0617.md
│   │   │   └── 0618.md
│   │   └── ...
│   ├── chips/
│   ├── oss/
│   ├── design/
│   └── monthly/
│
├── entities/                      ← 第二层：实体卡片
│   ├── nvidia.json
│   ├── openai.json
│   ├── tsmc.json
│   ├── meta.json
│   ├── huawei.json
│   └── ...
│
├── relations/                     ← 实体间关系
│   ├── supply_chain.json          ← "英伟达→TSMC: 代工"
│   ├── compete.json               ← "OpenAI vs Google: 模型竞争"
```
