## 二、P0 实施成果

### DSG-001 报纸头版布局

**文件：** `index.html`

**改了什么：**
- 删除了原有的"今日概览"卡片区（4 张 feature cards）和"频道速览"卡片区
- 新增 `frontpage-grid` 区域，采用 2 列报纸头版布局，直接展示所有 5 个频道的今日信号摘要
- 每个频道区块展示最多 3 条核心信号（标题 + 摘要，CSS `line-clamp: 2` 自然截断）
- 每个区块右上角附带"看完整日报 →"链接
- 第 5 个频道（月报）在桌面端跨两列展示

**关键差异：**

| 维度 | 改之前 | 改之后 |
|------|--------|--------|
| 首屏信息量 | 4 个标题 + 480 字摘要 | 最多 15 条信号标题 + 摘要 |
| 点击路径 | 首页 → 频道列表 → 文章（2-3 层） | 首页直接可读所有频道（0 层） |
| 布局模式 | 均等卡片网格 | 报纸专栏式，2 列布局 |
| 频道视觉区分 | 无 | 每频道独立左边框色 |
| 摘要截断方式 | `slice(0, 120)` 暴力截断 | `line-clamp: 2` 自然折行 |

### DSG-004 归档页摘要预览

**文件：** `channels/*/index.html`（5 个频道页）

**改了什么：**
- 每个频道列表页末尾注入 JS 脚本
- 脚本异步加载 `../../search/index.json`，按日期匹配该频道信号
- 找到每日期 Top 1 信号标题，动态注入 `<div class="archive-summary">` 到对应 `.archive-item`
- 无数据时静默跳过，不影响已有功能

**CSS 新增：**
```css
.archive-item .archive-summary {
    font-size: 0.8125rem;
    color: var(--text-secondary);
    margin-top: 6px;
    line-height: 1.5;
    /* 单行省略 */
    -webkit-line-clamp: 1;
}
```

**关键差异：**

| 维度 | 改之前 | 改之后 |
|------|--------|--------|
| 归档列表内容 | 仅日期 + "XX日报 — 2026-06-17" | 日期 + 日报标题 + Top 1 信号摘要 |
| 信息价值 | 用户不知道每天有什么内容 | 一眼看到每日核心信号 |
| 数据来源 | 纯静态 HTML | 动态从 index.json 注入 |

### DSG-005 文章详情页 ToC 目录

**设计：**

桌面端（≥768px）：
```
┌──────────────────────────┬──────────┐
│                          │  📑 目录  │
│  文章正文                 │  ──────── │
│  ## 概述                  │  ● 概述   │
│  ## 重大信号              │  ● 重大信号│
│  ### 信号1               │  ● 明日关注│
│  ## 明日关注              │           │
│                          │           │
└──────────────────────────┴──────────┘
```

- 右侧固定定位（`position: sticky; top: 80px`），宽度 200px
- 自动扫描 `h2` 标签生成目录项
- 当前阅读位置高亮（IntersectionObserver）
- 移动端（<768px）：顶部折叠式 `<details>` 展开

**CSS 关键代码：**
```css
.article-toc {
    position: sticky;
    top: 80px;
    width: 200px;
    flex-shrink: 0;
    max-height: calc(100vh - 100px);
    overflow-y: auto;
    padding: 16px;
    background: var(--bg-card);
    border-radius: var(--radius);
    border: 1px solid var(--border);
}
```

## 五、已知限制

1. **日报文章页**（`channels/*/YYYY-MM-DD.html`）未改动——这些由 Markdown → HTML 转换生成，ToC（DSG-005）需要在转换环节注入或通过全局 JS 扫描 `h2` 实现
2. **search/index.json** 是数据源——如果该文件尚未由构建系统生成，首页将显示"频道待首次产出…"，归档摘要不会显示
3. **频道配色**需与导航 logo、favicon 等在后续统一——当前仅应用于 CSS 中定义的元素
4. **移动端汉堡菜单**（DSG-008）涉及 JS 交互逻辑和遮罩层，需要更多实现时间，已纳为 P1
