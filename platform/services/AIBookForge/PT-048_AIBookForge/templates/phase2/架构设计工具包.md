> **说明**：本工具包承接《书籍立项书》，是"为自己写一本书"任务的第二阶段核心工具。

## 工具一：概念图谱绘制

> **功能**：在动笔之前，先画出这本书的"概念宇宙"——所有核心概念及其相互关系。

### 1.1 核心概念清单

请列出本书涉及的所有**核心概念**（至少10个，不超过30个）：

| 概念名称 | 初步定义 | 难度等级（1-5） | 与该领域的关系（核心/支撑/延伸） |
|:---|:---|:---|:---|
| 例：监督学习 | 通过标注数据训练模型学习映射关系 | 4 | 核心 |
| 1. | | | |
| 2. | | | |
| 3. | | | |
| … | | | |

### 1.2 概念关系图

将以上概念之间的关系用图示或文字描述。

**关系类型**：
- **A → B**：A是B的前置知识（必须先懂A才能懂B）
- **A ⊂ B**：A是B的子概念
- **A ≈ B**：A和B是类比/同层次概念（适合放在同一章对比学习）
- **A ≠ B**：A和B容易混淆，需要刻意区分

**绘制区域**：

```
（在此画出概念关系图）

例：
                    ┌─────────────────┐
                    │   监督学习       │
                    └────────┬────────┘
                             │
              ┌──────────────┼──────────────┐
              ▼              ▼              ▼
        ┌──────────┐  ┌──────────┐  ┌──────────┐
        │ 回归问题  │  │ 分类问题  │  │ 评估指标  │
        └──────────┘  └──────────┘  └──────────┘
```

### 1.3 概念一致性检查

- □ 同一个概念在全书中有没有可能使用多个不同名称？（如有，统一为一个）
- □ 是否存在"先用了术语、后解释定义"的情况？（如有，调整顺序）
- □ 哪些概念是"伪概念"——听起来很重要，实际上并不需要？（删除）
- □ 我能否用一个统一的"概念地图"在第一页给读者预览？（这个读者就是你自己）

### 5.3 指令模板库（核心章节类型）

**模板A：概念解释型章节**

```text
【角色】你是[领域]的科普作家，风格[参照风格]。
【任务】请解释"[核心概念]"，面向[受众描述]。

【约束】
① 避免使用专业术语（除非已定义）
② 每个新概念出现时，必须紧跟一个"换句话说"的通俗转译
③ 段落不超过5行

【风格参照】
[粘贴风格锚点中的示例段落]

【格式】
第一部分：核心定义（一句话）
第二部分：通俗解释（带类比）
第三部分：一个完整案例
第四部分：常见误解澄清
```

**模板B：案例叙事型章节**

```text
【角色】你是一个[领域]故事的讲述者。
【任务】通过[核心案例]，讲清楚[核心原理/概念]。

【约束】
① 故事必须真实（不得虚构人物/事件）
② 案例结束后，必须提炼出一般性结论
③ 与前后章节的概念有明确呼应
```

> **常见误区提示**：不要在写作过程中每次重新发明指令结构。
> 初期花1-2小时建立模板库，后期写作效率至少提升3倍。

## 工具六：检查点体系

> **功能**：明确全流程中的6个检查点，确保不偏离目标。

### 6.1 检查点清单

| 检查点 | 执行时机 | 负责填写 | 核心问题 | 门禁标准 |
|:---|:---|:---|:---|:---|
| CP-1 | 写作前 | 学员 | 核心命题是否仍成立？ | 立项书10项自检≥7通过 |
| CP-2 | 架构完成后 | 学员自审 | 依赖图无循环？认知坡度合理？ | 依赖图无循环+每章有坡度设计 |
| CP-3 | 每1-2章后 | 学员 | 风格是否偏离锚点？ | 风格锚点5项全对照 |
| CP-4 | 全书50%时 | 学员+导师 | 内容是否与蓝图一致？ | 偏差章节≤2个 |
| CP-5 | 初稿完成后 | 学员 | 核心问题是否得到回答？ | 验收标准逐条核对 |
| CP-6 | 终稿完成后 | 学员 | 验收标准是否达成？ | 全部验收标准已核对 |
