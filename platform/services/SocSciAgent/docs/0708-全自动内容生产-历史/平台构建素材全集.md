## 1.1 统一标签体系

### 1.1.1 内容属性标签（Content Tags）

内容属性标签定义知识节点的内在特征，是模板匹配、选材评分和编排决策的一级索引键。

**叙事类型标签**

| 标签ID | 含义 | 触发条件 |
|--------|------|----------|
| `#scene_setting` | 场景铺垫 | 描述时代氛围、地理环境、制度背景 |
| `#event_trigger` | 事件触发 | 一个具体行动/决策启动叙事链 |
| `#decision_point` | 决策点 | 人物面临A/B选择的关键时刻 |
| `#consequence` | 后果展现 | 决策/事件的直接与间接影响 |
| `#turning_point` | 转折点 | 历史轨迹发生方向性改变 |
| `#micro_event` | 微观事件 | 一件小事/一封奏折/一次偶然 |
| `#climax_decision` | 高潮决策 | 不可逆的历史性抉择 |
| `#counterfactual` | 假设分析 | 含"假如…"推理空间 |

**分析类型标签**

| 标签ID | 含义 | 典型模板 |
|--------|------|----------|
| `#institutional_analysis` | 制度分析 | TPL-01, TPL-03 |
| `#long_term_causality` | 长周期因果 | TPL-09 |
| `#comparative_history` | 比较史学 | TPL-04 |
| `#structural_explanation` | 结构解释 | TPL-01, TPL-03 |
| `#technological_breakthrough` | 技术突破 | TPL-05 |
| `#intellectual_crisis` | 思想危机 | TPL-06 |
| `#social_restructuring` | 社会重组 | TPL-05 |

**人物维度标签**

| 标签ID | 含义 |
|--------|------|
| `#character_trait` | 性格特质刻画 |
| `#motivation` | 动机分析 |
| `#contradiction` | 内在矛盾/两难 |
| `#individual_agency` | 个人能动性 |
| `#idealistic_actor` | 理想主义者 |
| `#ordinary_people` | 普通人/底层 |
| `#great_man_focus` | 英雄史观视角（通常被结构史观discourage） |

**史学立场标签**

| 标签ID | 含义 |
|--------|------|
| `#materialist` | 唯物主义立场 |
| `#cultural` | 文化史立场 |
| `#great_man` | 英雄史观 |
| `#structural` | 结构主义 |
| `#structural_determinism` | 结构决定论 |
| `#revisionist_evidence` | 修正主义证据 |

**知识类型标签**

| 标签ID | 含义 |
|--------|------|
| `#concept_intro` | 概念引入 |
| `#analogy` | 类比说明 |
| `#formal_def` | 形式化定义 |
| `#derivation` | 推导过程 |
| `#experiment` | 实验/证据 |
| `#boundary_misconception` | 边界/误区澄清 |
| `#historical_note` | 历史注记 |
| `#philosophical_implication` | 哲学含义延展 |

**难度/深度标签**

| 标签ID | 含义 |
|--------|------|
| `#layman` | 大众读者（无需前置知识） |
| `#enthusiast` | 爱好者（有一定基础） |
| `#technical_appendix` | 技术附录级（可跳过） |

### 1.2.2 选材加权字段详解

**significance各维度（0.0--1.0）**：

| 维度 | 含义 | 示例值（张居正事件） |
|------|------|----------------------|
| `political` | 政治重要性 | 0.6 |
| `economic` | 经济重要性 | 0.2 |
| `cultural` | 文化/思想重要性 | 0.8 |
| `personal_agency` | 个人能动性权重 | 0.5 |
| `symbolic_power` | 符号/象征力量 | 0.9 |

**dramatic_potential属性**：

```json
"dramatic_potential": {
  "has_dramatic_irony": true,
  "has_moral_dilemma": true,
  "has_visible_consequence": false,
  "has_counter_intuitive_element": true,
  "score": 0.85
}
```

`score` 取值范围 0.0--1.0，由领域专家/编辑标注。

**source_quality**：

```json
"source_quality": {
  "primary_sources": 2,
  "reliability": "high",
  "contemporary": true
}
```

`reliability` 取枚举值：`high` | `medium` | `disputed` | `low`。

**narrative_fit_tags**：数组，标注该节点适合哪些叙事意图，如`["INTENT_TRAGEDY", "INTENT_MICRO", "INTENT_REVISION"]`。

**typical_reader_resonance**：对象，key为读者画像ID，value为0.0--1.0的共鸣度预标注。

```
StylePack
 ├─ Layer 0 · Meta          （适用体裁、目标受众、禁止项列表）
```

### 1.3.6 文风包逆向工程完整SOP

**目标**：从标杆科普/历史文本中，系统提取显式可观测的语言特征，编码为规则/池子/权重。

**工序**：

1. **样本准备**
   - 选纯文本正文说理段，排除对话体访谈、Q&A、序跋、目录、参考文献
   - 同一作者3--5万字（约1--2本书核心章节）
   - 对比组：同期同题材其他作者样本（用于TF-IDF差分提取个性特征）

2. **TF-IDF差分提取（Layer 2 Lexical Pool）**
   - 分词 → 过滤停用词 → TF-IDF（目标 − 对照组）
   - 人工从Top-200高分词中挑「风格承载词」而非主题词
   - 分类填入：openers / connectors / analogy_triggers / forbidden_words

3. **人工标注（Layer 1 Persona + Layer 4 Rhetorical Ops）**
   - 三轴打分（1--5）：亲昵度Intimacy / 权威度Authority / 戏剧化Drama
   - 随机抽100--150个说理单元，标注：隐喻密度、类比来源域、类比位置、设问模式、数学处理方式

4. **量化校验（Layer 3 Syntactic Bias）**
   - 可量化特征：平均句长、问句比例、破折号/省略号频率、被动语态比例、段落平均行数
   - 写入约束而非复制分布（如`avg_sentence_len: short`，而非精确值）

5. **盲评测试**
   - 生成3段（本体系+文风包）混入2段真实原作者片段（去掉署名）
   - 请5--8位目标读者做「哪几段感觉是同一作者写的」多选
   - 命中率 >60% 为可用v1，>75% 为优质

6. **迭代**
   - 偏差定位：缺某类连接词？类比位置错？公式太突兀？
   - 只改YAML/池子，不改模板逻辑、不碰模型

### 1.4.4 史观包 ≠ 文风包的论证（必须拆开的理由）

| 维度 | 文风包 | 史观包 |
|------|--------|--------|
| 管什么 | 怎么说（口语化？书面化？句式偏好？） | 说什么、站在什么立场、褒谁贬谁 |
| 举例 | 用"换言之"还是"说白了" | 说"制度困境"还是"昏君误国" |
| 变化频率 | 同一史观可配多种文风 | 史观一变，禁止词表、情绪基调全变 |
| 耦合风险 | 如果把立场塞进文风包，改史观就要重建文风包，违背"正交参数"原则 |

**结论**：史观 ≠ 文风，必须在配置层正交拆开。

# 第二部分：叙事模板库（10种完整规格）

> 设计原则：模板 = 单元编排规则 + 约束条件 + 表现力锚点。模板不是写作套路（那是Prompt），而是可被规则引擎执行的单元组装指令。

---

## TPL-01｜「小事撬动大局」模板（黄仁宇式）

**适用**：制度史、政治史、长周期因果分析

**核心逻辑**：微观事件 → 宏观结构跃升

**叙事块结构（单元顺序详列）**：

```
[情境单元 Context Unit]  日常/边缘事件（一封奏折、一次迟到）
[事件单元 Event Unit]     事件被制度放大
[人物单元 Actor Unit]     当事人无力感
[结构单元 Structure Unit] 揭示制度/财政/军事深层矛盾
[反思单元 Reflection Unit] "这不是一个人的失败，而是一个系统的宿命"
```

**关键约束**：

```yaml
required_tags: [#micro_event, #institutional_constraint]
forbidden_tags: [#heroic_triumph]
transition_rule: event_unit → structure_unit (mandatory)
style_injection:
  structure_unit: use_macro_language, avoid_moral_judgment
```

**PDL新增槽位**：
- `iceberg_marker`：指出水面下更大的结构（"这只是冰山一角…"）
- `ticking_clock`：如果存在时间压力（如灾荒临近、敌军将至），必须点明

**张力弧线映射**：`narrative_hook → slow_buildup → dramatic_irony → structural_reveal`

**示例说明**：万历十五年，一封关于官员考核的普通奏折，暴露出整个文官集团与皇权的结构性死结。

**角色亲和度评分**：

| anchor_event | deep_dive | counterpoint | macro_frame | synthesis | bridge |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **3** | 2 | 1 | 2 | 0 | 2 |

## TPL-02｜「命运抉择时刻」模板（通俗传记式）

**适用**：人物中心叙事、关键历史转折点

**核心逻辑**：压力 → 抉择 → 不可逆后果

**叙事块结构**：

```
[情境单元]      外部压力汇聚
[人物单元]      性格/动机刻画
[事件单元]      关键抉择（A vs B）
[后果单元]      短期胜利 / 长期败局
[反思单元]      假如另一种选择？
```

**关键约束**：

```yaml
required_tags: [#decision_point, #character_trait]
psychological_portrayal: deep
allow_counterfactual: true
style_injection:
  decision_point: slow_motion, internal_monologue
```

**PDL新增槽位**：
- `stakes_clarity`：清晰列出选择的代价（不仅是得失，更是价值观冲突）
- `path_not_taken`：简短描绘未被选择的道路（制造"假如"的痛感）

**张力弧线映射**：`narrative_hook → rising_tension → climax_decision → reflective_close`

**示例说明**：鸿门宴上，项羽放走刘邦——那一刻，不是仁慈，而是政治直觉的缺席。

**角色亲和度评分**：

| anchor_event | deep_dive | counterpoint | macro_frame | synthesis | bridge |
|:---:|:---:|:---:|:---:|:---:|:---:|
| **3** | 2 | 0 | 0 | 1 | 1 |

```

[情境单元]      制度环境介绍
[事件单元]      试图修补/对抗制度
```

# 第三部分：编排引擎规范

## 3.1 模板选择器

### 3.1.1 模板评分公式完整定义

```
TemplateScore = α·LabelOverlap + β·StructuralFit + γ·NarrativePotential + δ·SourceRichness + ε·HistoriographyMatch
```

### 3.1.2 各项计算方式

**α·LabelOverlap（标签重合度，权重0.40）**：

```python
def label_overlap_score(node_labels, tpl_preferred_labels):
    score = 0
    for category in tpl_preferred_labels:
        intersection = len(set(node_labels[category]) & set(tpl_preferred_labels[category]))
        union = len(set(node_labels[category]) | set(tpl_preferred_labels[category]))
        score += (intersection / union) if union > 0 else 0
    return normalize(score)
```

**β·StructuralFit（结构契合度，权重0.25）**：

```python
def structural_fit_score(node, tpl):
    score = 0
    if tpl.id == "TPL_01" and node.relations.part_of:
        score += 0.3    # 属于更大历史进程
    if tpl.id == "TPL_02" and node.relations.contradicts:
        score += 0.4    # 存在对立叙事
    if tpl.id == "TPL_04" and len(node.relations.compares_with or []) > 0:
        score += 0.5    # 有可比对象
    return score
```

**γ·NarrativePotential（叙事潜力，权重0.20）**：

```python
def narrative_potential_score(node):
    score = 0
    if "#dramatic_irony" in node.labels.narrative_potential:
        score += 0.4
    if "#moral_dilemma" in node.labels.narrative_potential:
        score += 0.3
    if node.meta.data_richness == "high":
        score += 0.3
    return min(score, 1.0)
```

**δ·SourceRichness（史料支撑度，权重0.10）**：`(primary_sources × reliability_factor) 归一化`。

**ε·HistoriographyMatch（史观匹配度，权重0.05）**：HP对节点significance向量的点积（结构史观偏好高political/institutional分）。

### 3.1.3 各权重建议值与适用场景调整

| 场景 | α(标签) | β(结构) | γ(戏剧) | δ(史料) | ε(史观) |
|------|---------|---------|---------|---------|---------|
| 默认 | 0.40 | 0.25 | 0.20 | 0.10 | 0.05 |
| 通俗大众版 | 0.35 | 0.20 | 0.30 | 0.10 | 0.05 |
| 学术通俗版 | 0.35 | 0.25 | 0.15 | 0.15 | 0.10 |
| 年轻读者版 | 0.30 | 0.20 | 0.35 | 0.05 | 0.10 |

### 3.1.4 三层漏斗模型

```
Layer 1：硬性过滤（Hard Filter）
   ↓ 淘汰明显不匹配（required_labels/forbidden_labels/scale）
Layer 2：加权评分（Scoring Model）
   ↓ 计算最佳匹配
Layer 3：语境修正（Contextual Adjustment）
   ↓ 章节位置偏见/前后文一致性/史观参数修正
```

**Layer 3修正规则**：

| 章节位置 | 偏好模板 | 修正逻辑 |
|----------|----------|----------|
| 开篇第1章 | TPL-01, TPL-04 | 需要建立宏大框架，加分 |
| 中间论证章 | TPL-03, TPL-05 | 深入制度/技术，加分 |
| 转折章 | TPL-02, TPL-08 | 需要戏剧性/反转，加分 |
| 结尾章 | TPL-09, TPL-10 | 长时段/复调反思，加分 |

前后文去重：`if previous_section.template == tpl.id: final_score -= 0.15`。
