📍 第一阶段：核心方法论与多体裁验证（R1-R2）
R1

V2.0 核心方法论——六大支柱

支柱核心内容
1. 底层哲学强约束（模型做选择题、填槽位，不做作文题）+ 受控多样性（情绪/文风/结构丰度显性建模为可枚举参数）
2. 五大资料库统一标签体系 + 动作模板库 + 领域知识库 + 文风包库 + 情绪语音模板库
3. 双阶段运行冷启动（一次性人工定义规则/模板/文风包）→ 全自动生产（标签驱动→模板匹配→文风/情绪注入→成品渲染，边际成本趋零）
4. 四层拆解课程→段落→知识点→帧/页面，每层受标签约束
5. 双形态输出动态可视化（动画/视频）+ 结构化文档（讲义/报告，多文风一键派生）
6. 核心壁垒决策主体=规则引擎而非模型概率；批量一致性极高；表现力参数化可审计；长期维护只需修改模板/标签而非重写Prompt

标杆验证：高中数学《函数单调性》——冷启动后，新增一个知识点从入库到全形态输出仅需分钟级。

🎨 第二阶段：文风包逆向工程与历史通俗作品设计（R3-R8）
R3

文风包逆向工程方法论

从标杆科普文本中系统提取显式可观测的语言特征，编码为规则/池子/权重——不是训练 LoRA，是白盒约束层。

五层形式化维度

  • Layer 0 Meta：适用体裁、受众、禁止项
  • Layer 1 Persona：叙述者角色（亲切向导/严谨工程师）
  • Layer 2 Lexical Pool：词汇池（连接词/开场语/类比触发词/禁词表），TF-IDF差分提取
  • Layer 3 Syntactic Bias：句式偏好（平均句长/问句比例/破折号频率/被动语态比例）
  • Layer 4 Rhetorical Ops：类比策略/设问模式/数学展示方式
  • Layer 5 Layout/Pacing：框类型偏好、张力弧线默认映射

校验与迭代

  • 样本准备：3-5万字纯文本 + 同期同题材对照样本
  • 盲评测试：生成片段混入真实片段，命中率>60%可用，>75%优质
  • 定量辅助：词汇分布JS散度、句长分布、破折号频率落入原作95%CI
  • 迭代：只改YAML/池子，不改模板逻辑、不碰模型

历史通俗作品设计 & 10种叙事模板

四层拆解适配

科普的「说理单元」变为历史版的「叙事块（Narrative Block）」——包含情境单元、事件单元、人物心理/动机单元、结构分析单元、反思/升华单元。

R6-R9

模板选择器 + COG 编排语法 + 角色亲和度矩阵

模板选择器评分公式

对每个知识节点，逐模板计算「TemplateScore = α·标签匹配度 + β·史观亲和度 + γ·读者适配度 + δ·戏剧性适配 + ε·前序兼容度」，选最高分。

COG 编排语法核心概念

六大章节角色

  • anchor_event：锚点事件/切入点
  • deep_dive：深入分析/制度解剖
  • counterpoint：反常规/对立视角
  • macro_frame：宏大叙事/长时段结构
  • synthesis：综合升华/全章总结
  • bridge：缓冲/过渡

编排校验引擎

  • 角色唯一性检查
  • 张力曲线单调性（非严格，趋势合理）
  • 过渡合法性验证
  • 节奏呼吸约束
  • 史观一致性检查

角色亲和度矩阵：10个模板 × 6个角色逐项打分（0-3分），系统可基于章节角色序列自动选角编排。

R10

心理动力学编排层（PDL）

历史通俗作品追求"有立场的共鸣"而非"共识性正确"——需要价值观/情绪注入和读者连接点挖掘。

三大新增参数层

参数层解决的问题核心设计
史观参数包价值观和立场注入立场向量（个人能动性/结构决定论/道德评判/英雄史观/群众能动性）+ 情绪基调 + 价值观关键词 + 模板偏好 + 情绪注入规则
读者画像知识连接点+情感连接点认知基线 + 认知桥梁域 + 情感原型 + 读者阻抗地图 + 深层需求 + 语言亲和度
PDL 规则层导演情绪、全程无尿点悬念构建策略 + 认知落差计算 + 张力阶梯设计 + 高潮设计（唯一最高点、慢节奏） + 呼吸段插入 + 钩子机制

六大钩子槽位

开篇悬念钩 / 认知落差钩 / 矛盾钩 / 信息差钩 / 高潮钩 / 结尾钩——每章标配「开篇悬念钩 + 结尾钩」+ 中间至少一个「信息差钩」或「矛盾钩」。

最小惊艳 Demo——《最后的"董事长令"》

基于崇祯十七年三月十八日的谕旨事件，严格按照 TPL-01 模板、`tragic_determinism_v1` 史观包、`burned_out_professional_v1` 读者画像和 PDL 规则，自动生成约 800 字的历史章节开头。验证了整套体系从配置到成品的完整闭环：不是编故事（所有史实真实）、不是堆砌知识（类比为现代公司治理语境）、是在导演情绪（从紧张→无力→宿命感）。

🔧 第四阶段：选材引擎与冲击力/主旋律（R13-R14）
R13

选材引擎（Material Selection & Weighting Engine）

教材=大纲驱动（知识点全集固定）；历史通俗作品=目标驱动（选材有自由度，需主动"挑戏"）。选材结果 = f(服务目标, 史观包, 读者画像)。

六种叙事意图（Narrative Intent）

INTENT_EPIC（宏大叙事）/ INTENT_MICRO（微观史）/ INTENT_TRAGEDY（制度悲剧）/ INTENT_REVISION（翻案修正）/ INTENT_PERSONAL（人物传记）/ INTENT_IDEATIONAL（观念史）

选材评分公式：S = α·IntentFit + β·DramaticPotential + γ·SourceQuality + δ·ReaderResonance + ε·HistoriographyBias。权重可随作品类型微调（通俗版↑δ，学术版↑γ）。作者可通过手工调权、锁定必选节点、微调权重向量来体现选材品味。

R14

冲击力注入层 + 主旋律记忆层

冲击力注入层（Impact Injection）

  • 冲击力 = 反常识密度 × 数据精确性 × 情绪唤醒度
  • 四类投放位置：开篇Hook / 矛盾升级点 / 高潮前静默 / 结尾Hook
  • 冲击力约束：非"标题党"，有来源，不歪曲史实

主旋律记忆层（Motif Layer）

  • 如音乐制作的 hook，让读者最终记住一两句话
  • 主旋律 = "一切宏大叙事的崩塌，始于技术治理的缺位"
  • 每章三节点（开篇暗线→高潮强奏→结尾变奏）+ 当代映射
  • 防空洞：必须落到具体知识点或读者当下问题上

R15-R17

五维对抗评审 Agent 体系

对抗Agent不参与生成，只参与评审和修改建议。它不改变"强约束+受控多样性"的哲学，而是加强约束的有效性。
Agent攻击目标核心攻击角度
Historiography Auditor史观一致性立场漂移、价值关键词违禁、情绪基调不一
Reader Advocate读者共鸣认知门槛过高、类比失效、情感错位
Narrative Critic叙事质量悬念造假、张力虚假、高潮疲软
Integrity Guardian真实性与冲击力数据失真、冲击力廉价、主旋律空洞
Perspective Challenger选材偏见视角单一、证据失衡

对抗评审发生在编排后、渲染前的核心关卡。本身也受审美约束——必须注入史观包、读者画像和审美标准，"不是自由的批评家，而是戴着镣铐的考官"。

R18-R19

系列品牌圣经 + 体系总览架构 V3.0

系列品牌圣经（Series Brand Bible）

系列级共享配置（Series Profile）作为所有单部作品的继承父配置：共享史观 + 共享主旋律 + 共享文风包（锁定禁止项）+ 共享模板偏好 + 冲击力政策 + 读者基调 + 品牌标识。通过"受控重复形成辨识度（品牌），通过受控变异保持不平庸（生命力）"。
