# SPDT-005 媒体内容制造 · 技术架构

> v1.0 | 2026-07-10

## 总览

SPDT-005 以 SmartTextPlatform 路由引擎为核心，实现全媒体内容类型的自动化制造与分发。

## 生产管线

```
┌─────────────────────────────────────────────────────┐
│                   INPUT                              │
│  NL 需求 / 数据源 / 监测信号                        │
└──────────────────────┬──────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│           SHARED SMARTTEXT ROUTER                    │
│  TextClassifier → 10维结构化 → 6集群路由            │
│  ├─ CLUSTER-B (深度) → PT-040                       │
│  ├─ CLUSTER-A (快反) → PT-041                       │
│  ├─ CLUSTER-E (科普) → PT-042                       │
│  ├─ CLUSTER-F (观点) → PT-043                       │
│  ├─ CLUSTER-C (创意) → PT-044                       │
│  └─ CLUSTER-D (技术) → PT-045                       │
└──────────────────────┬──────────────────────────────┘
                       ↓
┌─────────────────────────────────────────────────────┐
│              PDT PIPELINE                            │
│  各 PDT 的 Stage 链（4-6 Stage）                    │
│  → 内容加工 → 风格注入 → 事实核查 → 人工兜底        │

                       ↓

                       ↓
┌─────────────────────────────────────────────────────┐
│              AUTOPUBLISH                             │
│  飞书 / 微信 / 网站 多渠道分发                      │
└─────────────────────────────────────────────────────┘
```

## 核心组件

### 1. SmartText 路由引擎 (shared/smarttext_router)

源自 SmartTextPlatform，提供统一的内容需求理解和分派。

| 组件 | 功能 |
|---|---|
| TextClassifier | NL → 10维结构化表示 |
| 6 集群路由 | 按内容类型分派到最适 PDT |
| decision_log | 全链路 Agent 工具调用追溯 |
| artifact | 跨 Guild 产物传递 |

### 2. PDT Stage 配置

| PDT | Stages | 特点 |
|---|---|---|
| PT-040 DeepProd | 选题→研究→写作→审阅→可视化→交付 | 6 Stage，最深管线 |
| PT-041 FlashNews | 监测→核查→撰稿→发布 | 4 Stage，速度优先 |
| PT-042 SciPop | 研究→转化→写作→审查 | 4 Stage，通俗化核心 |
| PT-043 OpEd | 研究→结构→写作→辩论 | 4 Stage，论证驱动 |
| PT-044 CreativeX | 简报→构思→创作→润色 | 4 Stage，创意探索 |
| PT-045 TechDoc | 规格→研究→撰写→审查 | 4 Stage，精确性优先 |

### 3. 发布通道 (channels/)

| 通道 | 来源 | 状态 |
|---|---|---|
| 飞书 | autopublish/channels/feishu | 就绪 |
| 微信公众号 | autopublish/channels/wechat_mp | 就绪 |
| 网站 | autopublish/channels/website | 就绪 |

## PDT 差异化

各 PDT 共享 SmartText 路由引擎，但各自维护：
- 独立的内容模板（templates/ 下）
- 独立的风格配置（语调/文风参数）
- 独立的领域知识库和事实核查规则
