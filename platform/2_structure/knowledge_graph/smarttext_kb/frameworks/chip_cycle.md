# AI 芯片周期框架

> 从芯片频道产出的中长期分析框架

## 周期阶段定义

1. **产能扩张期**：新建 Fab/产线 → 12-18 个月 → 产能释放
2. **技术迭代期**：新制程/新架构 → 6-12 个月 → 产品升级
3. **供需失衡期**：需求暴涨 + 产能有限 → 价格上涨 → 排队
4. **出口管制冲击**：政策变化 → 即时影响 → 供应链重组

| 指标 | 观测频率 | 数据来源 |
