# 《为自己写一本书 · 认知跃迁自评体系》v1.0

> **说明**：本SOP是第四阶段（整合复盘）的核心工具。
> 核心逻辑是牵引**元认知品味**和**伦理品味**。
> 终极目标：让学习者清晰描述"我真正学会了什么"与"我以为我学会了什么"之间的差距。

---

## Step 1：全书一致性审查

### 1.1 章节间一致性检查

- □ 每章的核心论点是否与全书的总命题一致？
- □ 哪些章节之间的跳跃比较大？需要补什么过渡内容？
- □ 同一概念在全书中是否使用了统一的名称？
- □ 章节间的依赖关系是否与依赖图一致？

### 1.2 认知坡度终审

- □ 全书的认知坡度是否整体平滑？有没有明显的"断层"？
- □ 最陡的章节，现在回头看坡度设计是否合理？
- □ 有没有因为"写完后才真正理解"而发现需要补充的预备知识？

### 1.3 验收标准逐条核对

回到立项书第五章的"学习目标验收"，逐条核对：

| 验收标准 | 达成情况 | 具体证据 |
|:---|:---|:---|
| 学完后，我能_____ | [已达成/部分达成/未达成] | |
| 学完后，我能_____ | | |
| 学完后，我能_____ | | |

## Step 4：AI贡献声明

> **功能**：说明AI在各阶段的具体贡献，以及"哪些部分坚决由人完成"。
> 这是**伦理品味**的核心体现。

### 4.1 AI贡献分布

| 阶段 | AI做了什么 | 人做了什么 | 贡献比例（AI/人） |
|:---|:---|:---|:---|
| 立项 | | | |
| 架构 | | | |
| 素材收集 | | | |
| 初稿生成 | | | |
| 修改润色 | | | |
| 事实核查 | | | |
| 整体评审 | | | |

### 4.2 AI贡献声明模板

```text
本人在本次"为自己写书"项目中，遵循以下AI使用原则：

1. AI辅助范围：
   - AI用于[具体列举]...
   - AI不可替代[具体列举]...

2. AI生成内容的核查情况：
   - AI生成内容共约[XX]字
   - 经人工核查发现[XX]处错误/幻觉
   - 错误类型：[事实错误/逻辑跳跃/案例虚构/其他]

3. 知识产权声明：
   - 本书中引用的资料来源均已标注
   - AI生成内容未作为原创学术观点呈现
   - 如有参考/改写AI内容，已明确说明
```
